# Conflicting values in individuals and organizations

This repository contains the data, analyses and figures for the paper "Conflicting values in individuals and organizations: Moral motives that promote and prevent retaliation against aggressive customers" by Sarah G. Milliron, John M. Doris, Kristin Smith-Crowe and Laura Niemi.

**Contents:**

- [Introduction](#introduction)
- [Repository structure](#repository-structure)
- [Preregistrations](#preregistrations)

## Introduction

Across four main studies and four supplementary studies, we examine how organizational policies emphasizing personal values or company expectations shape responses to aggressive customers. We also examine deservingness and obligation to the employer as possible explanations for these responses.

## Repository structure

```text
├── code
│   └── R
├── data
│   ├── main
│   │   ├── study1
│   │   ├── study2
│   │   └── study3
│   │       ├── a
│   │       └── b
│   └── supplementary
│       ├── study1
│       ├── study2
│       ├── study3
│       └── study4
├── docs
│   └── index.html
├── figures
│   ├── main
│   └── supplementary
└── materials
    ├── main
    └── supplementary
```

- `code/R/` contains the analysis notebook used to analyze the data and generate figures (view the rendered notebook [here](https://explanation-lab.github.io/compliance_and_agency/)).
- `data/` contains anonymized data from all eight studies.
- `docs/` contains the rendered analysis for viewing in a browser.
- `figures/` contains the paper's figures, organized by study using the same structure as `data/`.
- `materials/` contains the available surveys and archived registrations, organized by study.
