# Conflicting values in individuals and organizations

This repository contains the data, analyses, figures and available study materials for the paper “Conflicting values in individuals and organizations: Moral motives that promote and prevent retaliation against aggressive customers” by Sarah G. Milliron, John M. Doris, Kristin Smith-Crowe and Laura Niemi.

## Introduction

How should organizations guide employees’ responses to aggressive customers? Across four main studies and four supplementary studies, participants imagined working under a policy emphasizing either their personal values (agency) or company expectations (compliance). They reported whether they would retaliate by undermining customer service or try to de-escalate the conflict. The analyses examine these behavioral differences and their associations with customers’ deservingness and employees’ obligation to the employer.

[View the analyses in your browser](https://explanation-lab.github.io/compliance_and_agency/).

- `code/R/` contains the paper’s R Markdown analysis, its rendered output and an RStudio project. The notebook includes the main-text analyses, registered main analyses and supplementary analyses.
- `data/` contains the analysis inputs for all eight studies. Participant IDs have been replaced with study-specific anonymous IDs; platform identifiers, location metadata and open-text responses are omitted. Row order, study variables and inclusion flags are retained. See the [data README](data/README.md).
- `docs/` contains the rendered analysis for viewing in a browser.
- `figures/` contains all eight study figures as PDF and 600-dpi PNG files, generated by `paper.Rmd`. Points show participant averages; black markers show observed group means and bars show 95% t confidence intervals.
- `materials/` contains the available survey PDFs, main-study descriptions transcribed from the manuscript, and archived registrations. Complete original main-study surveys and executable study implementations were not available. See the [materials README](materials/README.md).

## Reproduce the analyses

Open [compliance_and_agency.Rproj](code/R/compliance_and_agency.Rproj) in RStudio, open [paper.Rmd](code/R/paper.Rmd), and click **Knit**. Install missing packages once:

```r
install.packages(c("tidyverse", "lmerTest", "emmeans", "boot", "knitr", "rmarkdown", "bookdown"))
```

From the repository root, with R and Pandoc installed:

```sh
Rscript --vanilla -e 'rmarkdown::render("code/R/paper.Rmd", output_file="paper.html", output_dir="code/R"); file.copy("code/R/paper.html", "docs/index.html", overwrite=TRUE)'
```

This regenerates the results displayed in the notebook, figures and browser version. The checked environment used R 4.5.2 and Pandoc 3.4; the notebook includes full session information. Its public inputs reproduce the working analysis results at tolerance 1e-7.
