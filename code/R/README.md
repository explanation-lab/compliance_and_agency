# Paper analysis

Open `compliance_and_agency.Rproj` in RStudio and Knit `paper.Rmd`. It contains the main-text Gaussian mixed models, emmeans comparisons, separate mediation, registered main analyses and the supplementary analyses.

All study figures show observed group means and 95% t confidence intervals calculated from participant averages. Model estimates remain in the statistical results.

Knit regenerates `paper.html` and the eight PDF/PNG figures. Results are displayed in the notebook. Copy `paper.html` to `../../docs/index.html` to refresh the public browser version, or use the render-and-copy command in the root README.
