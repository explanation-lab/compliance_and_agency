# Paper analysis

Open `compliance_and_agency.Rproj` in RStudio and Knit `paper.Rmd`. It contains the main-text Gaussian mixed models, emmeans comparisons, separate mediation, registered main analyses and the supplementary analyses with labeled sensitivities.

All study figures show observed group means and 95% t confidence intervals calculated from participant averages. Model estimates remain in the statistical results.

Knit regenerates `paper.html`, `paper_results.txt`, `paper_comparisons.csv` and the eight PDF/PNG figures. Copy `paper.html` to `../../docs/index.html` to refresh the public browser version, or use the render-and-copy command in the root README.
